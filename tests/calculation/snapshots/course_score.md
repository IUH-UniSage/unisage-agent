**Điểm tổng kết học phần (lý thuyết + thực hành)**

Công thức:
- ĐLT = 20% × TBtx + 30% × GK + 50% × CK
- ĐTH = (TH1 + TH2 + … + THn) / n
- ĐTKHP = (ĐLT × TCLT + ĐTH × TCTH) / (TCLT + TCTH), làm tròn đến 0.1

Số liệu:
- Tín chỉ lý thuyết: 2
- Tín chỉ thực hành: 1
- Điểm thường xuyên: 8
- Điểm giữa kỳ: 7
- Điểm cuối kỳ: 6.5
- Điểm thực hành: 9, 8

Thay số:
1. Điểm lý thuyết: ĐLT = 0.2 × 8 + 0.3 × 7 + 0.5 × 6.5 = 1.6 + 2.1 + 3.25 = 6.95
2. Điểm thực hành: ĐTH = (9 + 8) / 2 = 17 / 2 = 8.5
3. Điểm tổng kết học phần: ĐTKHP = (6.95 × 2 + 8.5 × 1) / (2 + 1) = 22.4 / 3 ≈ 7.47
4. Làm tròn: ≈ 7.47 → 7.5
5. Quy đổi: 7.5 thuộc khoảng [7.0; 8.0) → B → 3.0

Kết quả: ĐTKHP **7.5** · Điểm chữ **B** · Thang 4 **3.0**
